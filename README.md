# Tsu-Han Su — GitHub Pages starter

This first version reproduces the available Biography/CV content from the uploaded Google Sites saved page. It is **not yet a complete mirror**. Other navigation links point to the original Google Sites pages until their HTML and images are provided.

## Deploy
1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `portrait.jpg` to the repository root.
3. Open Settings → Pages → Build and deployment → Deploy from a branch.
4. Select `main` and `/ (root)` and Save.
5. Visit `https://USERNAME.github.io/REPOSITORY/`.

No build tools required.
